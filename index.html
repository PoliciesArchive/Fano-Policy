Fano Host Basic Policy

See how Gift Share, Host Share and Room Bonus add up to your diamonds.

Host policy

Gift Share

If a host receives 900K coins, the host receives 900K diamonds in their wallet.

Host Share

The host automatically receives 200% of the Gift Share.

Example: if a host receives 900K diamonds, they receive an extra 1.8M diamonds as Host Share.

Room Bonus

The host receives 30% of the room receiving.
